# RayuCode Agentic action

This repository-local JavaScript action runs the published Rayu CLI in GitHub
Actions. It supports two modes:

- `assistant`: implements a trusted request, validates the changed paths, then
  commits and pushes the result. Issue requests are published in a new pull
  request; pull-request comments update the same-repository head branch.
- `review`: runs Rayu with plan permissions and posts a Markdown review without
  modifying the repository.

The supported workflow is generated by the Rayu `/install-github-app` command.
The action deliberately installs the CLI before placing `RAYU_API_KEY` in the
process environment, strips GitHub credentials from the agent process, and uses
an ephemeral askpass helper only when publishing validated changes.

For the action stored in this repository, use:

```yaml
- uses: Choeng-Rayu/rayu-cli/rayu-action@main
  with:
    rayu_api_key: ${{ secrets.RAYU_API_KEY }}
    github_token: ${{ secrets.GITHUB_TOKEN }}
```

For stable releases, replace `main` with a release tag or full commit SHA.
