## Coupling note

**151 of 165** ORIGINAL files import from the local module graph, i.e. they are **built on top of the DERIVATIVE core** (the tool framework `src/Tool.ts`, agent framework `src/tools/AgentTool/`, query engine `src/query.ts` / `src/QueryEngine.ts`, the custom Ink TUI renderer `src/ink/`, provider adapters, and config/permission systems). The first-party features are therefore **not cleanly separable** from the derivative core as-is: lifting them onto a clean-room or permissively-licensed base would require re-implementing those shared foundations. This is the key structural fact for the legal/architecture decision.

## De-risk actions already applied (see un-use-code/README.md)

- Anthropic telemetry (GrowthBook/Statsig feature flags + first-party event logging) **neutralized to no-op stubs**; network exporter + GrowthBook dependency removed.
- **claude.ai subscription OAuth login removed** (BYO `ANTHROPIC_API_KEY` and other providers retained).
- **CCR upstream proxy removed**; remote-session URLs **de-pointed from claude.ai** to a Rayu-configured host.
- Telemetry is **off by default** (`RAYU_TELEMETRY`), and an active OpenAI-compatible provider forces essential-traffic-only.

Note: a theme color token literally named `"claude"` remains in ~40 UI files. It is an internal design-token identifier (not user-visible text); renaming is cosmetic and deferred to avoid churn.
