## [1.4.476] - 2026-07-17

### Added
- Multi-provider AI support (Anthropic, OpenAI, DeepSeek, Gemini, Bedrock)
- Telegram bot integration for remote access
- Image and video generation tools
- 94+ slash commands for development workflows
- 48+ built-in tools
- 20+ bundled skills
- Optional centralized billing via rayu-backend
- MCP (Model Context Protocol) server integration
- Custom React/Ink terminal renderer
- Comprehensive permission system

### Changed
- Forked from Claude Code with significant modifications
- Enhanced provider abstraction layer
- Improved state management with Zustand-like stores

### Fixed
- Various stability improvements
- Performance optimizations

## Release Types

### Major (x.0.0)

### Minor (1.x.0)
New features, backward compatible

### Patch (1.4.x)
Bug fixes, backward compatible
